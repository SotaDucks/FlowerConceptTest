# NATURE RECONSTRUCTION／自然重建 — 七镜头 UI 播放器

依据 `nature-reconstruction-ui-plan.md` 制作的网页屏幕视觉系统。七个镜头共用一条影片时间轴，画面完全由时间决定：同一时间点永远得到同一帧，可以任意拖动、跳转或逐帧步进。

## 运行

```bash
npm install
npm run dev
```

如果下载了本地文件，则所以必须通过本地服务器打开，不能直接双击 html。打包用 `npm run build`，再用 `npm run preview` 预览（可以让你的Agent操作）。

在线版本：https://sotaducks.github.io/FlowerConceptTest/ 。

## 播放器

| 操作 | 快捷键 |
| --- | --- |
| 播放／暂停 | Space |
| 逐帧前进／后退 | → ／ ← （Shift 为 1 秒） |
| 跳到镜头 1–7 | 1 – 7 ，或 PgUp ／ PgDn |
| 循环当前镜头 | L |
| 纯净画面（隐藏播放器，用于录屏） | H，Esc 退出 |
| 全屏 | F |
| 底图标定 | C |

右侧 LAYERS 按钮可单独开关 BG（底色网格）、PLATE（植株／三维／人像）、UI（文字与图形）、FX（颗粒、扫描线、暗角），用于分层输出。关闭 BG 时背景透明。

URL 参数：`?shot=3&t=4.2`（跳转）、`play=0`（不自动播放）、`clean=1`（纯净画面）、`loop=1`、`layers=ui,fx`、`fps=24`（默认 25）。

### 逐帧导出接口

页面暴露 `window.NR`：`NR.frame(n)`／`NR.seek(秒)` 跳到指定帧，`NR.layers(['ui'])` 切换图层，`NR.duration`、`NR.shots` 给出时长与各镜头起点。配合 Playwright／Puppeteer 逐帧调用后截图，即可按指定帧率输出序列帧；截图时打开 `omitBackground` 并关闭 BG，即可得到带透明通道的 UI 层。

## 修改文案、数据与底图

- **全部文案与数据**都在 `src/content.js`：物种资料、镜头七的档案字段、匹配度、雷达值、行为记录、DATA LOG、剧情时钟等。
- **替换底图**（镜头 3／4／5）：覆盖 `img/镜头345图片.png`，或修改 `content.js` 顶部的 import。换图后按 **C** 进入标定：拖动青色点（植株轮廓）、白色方块（器官锚点）、琥珀色角点（器官框）对准新图，再把右侧 JSON 粘贴进 `content.js` 的 `PLATE`。点「APPLY + RELOAD」可以先在本机浏览器里临时生效。

## 各镜头实现

| 镜头 | 时长 | 实现 |
| --- | --- | --- |
| 1 自然重建 | 9.0 s | Three.js 程序化紫纹兜兰（网格斑纹叶、条纹中萼片、带疣点的花瓣、囊状唇瓣），依次经过点云 → 轮廓线框 → 表面三个重建阶段；摄影机缓慢绕行 |
| 2 重构完成 | 4.6 s | 加载线停在 100%，定位框闭合，显示「重构完成／形态重构完成」，随后定位框展开进入 VR 环境 |
| 3 植株扫描 | 20 s | 底图边缘特征点扫描；依次分析全株 → 叶片形态 → 网格纹理 → 花朵与唇瓣，当前器官保留自然色，局部放大图直接取自底图同一位置；SAMPLE 017 在建档时转为 SPECIMEN 017 |
| 4 生存环境 | 20 s | 植株缩小成节点，并入三维林下剖面（苔藓溪谷、腐殖质／多石／岩缝地层、林冠）；依次出现关系线、生境斑块断开、微气候变化、个体被移除；分布图仅作示意 |
| 5 数据残缺 | 9.0 s | 栖息地图层在采集边界处缺块，传粉路径以虚线延伸至未知区域，地下数据只画网格与未闭合的采集边界（无数据，不画成零），系统照常给出「稳定」 |
| 6 关闭失败 | 5.0 s | 沿用镜头五界面：先收拢、停住，再弹回原状，红色只用于失败结果与一个状态标记 |
| 7 样本登记 | 22 s | SDF 光线步进的全息头像扫描，沿用镜头三的身份条位置与扫描框；揭示顺序为 人像 → SPECIMEN 000 → HUMAN／人类 → ACTIVE，之后填入其余档案 |

总长 89.6 秒。各镜头的时长与时间点写在对应的 `src/shots/shotN.js` 顶部，可以按剪辑需要调整。

## 目录

```
src/
  content.js          文案、数据、底图标定
  core/               时间轴引擎、时间驱动的出现动画、工具函数、底图预处理
  components/         共享组件：扫描框、连接线、面板、身份条、图表、全局 HUD
  gl/                 Three.js：兰花模型、生境剖面、人像 SDF
  shots/              七个镜头
  player/             播放器与底图标定
  styles/             视觉规范与各镜头样式
```

## 目前的替代素材

- 镜头一的兰花是程序化模型，能看出物种的识别特征，但不是标本级精度。如需准确模型，可以改为加载 glTF／GLB。
- 镜头七的人像是程序生成的占位扫描，拿到主角的照片或片段后再替换。
- 镜头四的分布图是粗略的点阵示意，只标出了资料提到的区域。
